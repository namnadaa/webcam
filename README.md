# Webcam noise and stability

A webcam application that measures camera noise and stability: dark and light noise,
non-uniformity (DSNU/PRNU), drift over time, signal-to-noise ratio of a modulated light source,
and a comparison of camera modes. The interface is available in English and Russian.

Программа для измерения шума и стабильности веб-камеры. Интерфейс на английском и русском.
